# INSTALLATION

This guide will allow you to install core and any extension you desire in case you're having trouble with it.

The steps are very similar also in Android, with a few quirks.

## First step

Change the flag in ``chrome://flags/#extension-mime-request-handling`` to ``Always prompt for install``.

If you aren't using Ungoogled Chromium or a fork, Ensure the following option is checked: Extension Options (chrome://extensions/?options=ocaahdebbfolfmndjeplogmgcagdmblk) > Advanced > Always download CRX files

## Second step

Install the .crx file [here](https://github.com/NeverDecaf/chromium-web-store/releases/latest)

## Final step

After downloading it, there should popup an option to add the extension to the browser, click "confirm" or something similar in your language.

You should be done after that and you should be allowed to install any extension.

Keep in mind that **Developer options** should be enabled if you want to install Core.

## Android

Go to extensions, tap on "Manage extensions", tap on Developer options to enable it, then tap "Load .crx"

Select the webstore .crx, and you should be good to go.

# Installing Core

Now that Chromium webstore is installed, we can proceed to the Core installation.

## Step 1

## Final step

Load from unpacked, then choose the normal folder if you're on PC.

If you're on Android, choose the android folder.
